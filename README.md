# News Summarizer (خلاصه‌ساز اخبار)

یک برنامه دسکتاپ مدرن و کاربردی برای دریافت، خلاصه‌سازی و نمایش اخبار از منابع مختلف خبری (فارسی و انگلیسی). این ابزار با استفاده از کتابخانه Tkinter ساخته شده و به شما کمک می‌کند بدون نیاز به مرور چندین سایت مختلف، در کوتاه‌ترین زمان از جدیدترین اخبار مطلع شوید.

### 🚀 ویژگی‌ها
* پشتیبانی دو زبانه: انتخاب آسان بین منابع خبری فارسی و انگلیسی.
* خلاصه‌سازی هوشمند: استفاده از الگوریتم مبتنی بر فرکانس کلمات (Word Frequency) برای استخراج خلاصه مفید از متن خبر.
* رابط کاربری مدرن (GUI): طراحی تمیز و زیبا با استفاده از تم تیره و فونت‌های خوانا.
* لینک‌های تعاملی: دسترسی سریع به منبع اصلی خبر با یک کلیک.
* شخصی‌سازی: امکان انتخاب تعداد اخبار مورد نظر.

### 🛠️ تکنولوژی‌های استفاده شده
* Python: زبان اصلی برنامه.
* Tkinter: جهت ساخت رابط کاربری گرافیکی (GUI).
* Requests & xml.etree.ElementTree: برای دریافت و پارس کردن فیدهای RSS.
* BeautifulSoup/Regex: برای پردازش و استخراج متن اخبار.

مخزن را کلون کنید یا فایل‌ها را دانلود کنید:
```bash
git clone https://github.com/your-username/news-summarizer.git
```
وارد پوشه پروژه شوید:
```bash
   cd news-summarizer
```
پیش‌نیازها (کتابخانه‌های مورد نیاز) را نصب کنید:
```bash
   pip install requests urllib3
```
برنامه را اجرا کنید:
```bash
   python main.py
```
### 🏗️ ساختار پروژه
* fetch_news.py: مدیریت دریافت و دسته‌بندی فیدهای RSS از منابع معتبر.
* summarizer.py: الگوریتم خلاصه‌سازی متون خبری با حذف کلمات توقف (Stop Words).
* main.py: رابط کاربری اصلی برنامه و مدیریت تعاملات کاربر.
